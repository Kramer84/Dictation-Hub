## Open items / notes
- **Not yet checked on real hardware:** a real local dictation and a real client → server round trip. These need a mic.
- **Decided:** phrases made only of filler words ("Yeah, sure.") are **kept**, because they can show intent or hesitation. What should go is the filler Whisper *invents*, usually at the end of a recording ("Thank you.", "Thanks for watching", "Sous-titres réalisés par…"). The dictionary has no rules for these yet, so a trailing-hallucination filter is still to do. A lone filler segment like "Yeah." is still dropped by `_is_pure_filler`, and that needs confirming.
- `HOST_BIND_IP`/`HOST_BIND_PORT` in `config.env` aren't read by any code. Wire them up or remove them in M1, along with the systemd unit.
- The user's copies under `~/.config/dictation_hub/` are not touched by these changes.
- Deferred to later milestones: D08 (recording keys, Ctrl-C killing `curl`) → M1. D09/D11 (16 kHz capture, normalization) → M1/M1b. D13 (GPU check) → M2. D05/D06 (client flags, completion) → M3. D15/D16/D24/D26 (config model, typed errors, REPO_ROOT) → step by step from M1.
